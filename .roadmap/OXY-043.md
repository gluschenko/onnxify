## Summary

Generated TorchSharp C# must never contain tensor weight values. Generation offers two runtime weight sources: load initializer tensors by name from the original ONNX file, or return a Safetensors sidecar built from the compiler tree. The generated module receives the source path in its constructor.

## Contract

- `Compiler.GenerateCSharp` returns `CompilerResult<IFile[]>`; the bundle contains one `SourceCodeFile` and, for Safetensors mode, one `BinaryFile`.
- `CompilerCSharpGenerationOptions.WeightStorage` selects ONNX or Safetensors at generation time.
- ONNX mode returns C# only; the caller supplies the source ONNX path when constructing the generated module.
- Safetensors mode returns C# and a `.safetensors` binary; the caller supplies that file path when constructing the module.
- Runtime loading validates initializer name, element type, and shape. No numeric or base64 inline fallback is permitted.

## Tests And Acceptance Criteria

- Verify returned artifact names, contents, tensor names, dtypes, shapes, and values for both storage modes.
- Compile and execute generated modules loading weights from ONNX and Safetensors, and compare both results to ONNX Runtime.
- Run compiler tests on net8.0 and net10.0, and exercise a large model such as AlexNet to demonstrate that weight volume no longer inflates C# source.
