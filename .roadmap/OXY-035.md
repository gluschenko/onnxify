## Summary

Extend the OXY-031 shape/factory mappings to support shape values and parameters computed from runtime tensor data. Preserve dynamic behavior through ONNX shape tensors and exact typed-node subgraphs.

## Depends On

- [OXY-031](OXY-031.md).
- [OXY-034](OXY-034.md).

## Goals

- Support runtime-derived shapes, axes, repeats, and factory dimensions for the deterministic upstream forms whose semantics have exact ONNX representations.
- Preserve symbolic input dimensions and runtime shape values through both compiler frontends and backends.
- Diagnose unsupported shape expressions, invalid ranks/dtypes, and incompatible runtime constraints without replacing them with compile-time approximations.
- Reuse OXY-031 operator mappings and abstractions rather than duplicate static and dynamic operator semantics.

## Non-Goals

- Do not implement pointwise operators, matrix operations, reductions, non-pointwise selection/indexing, or nondeterministic factories.
- Do not change public compiler APIs.

## Tests

- Add paired ONNX-to-TorchSharp and TorchSharp-to-ONNX tests for runtime-computed shape and factory cases.
- Compile and execute generated TorchSharp, create ONNX Runtime sessions, and compare deterministic outputs.
- Assert typed ONNX node/subgraph structure and diagnostics for invalid or unsupported runtime forms.
- Cite exact ONNXScript `TorchLibOpInfo` cases in `third_party/onnxscript/tests/function_libs/torch_lib/ops_test_data.py` and ONNX Runtime source tests in each operator fixture. Initial candidates include `aten_reshape`, dynamic `aten_expand`, dynamic repeat counts, and runtime `arange` bounds; confirm each against the selected ONNX Runtime tests before implementation.

## Acceptance Criteria

- Every declared runtime-shape/factory case has paired verification or an explicit tested diagnostic and documented limitation.
- Dynamic shape values are preserved end to end without being replaced by initializers or guessed metadata.
- `Onnxify.Compiler.Tests` passes on `net8.0` and `net10.0`; all compiler target frameworks build.
