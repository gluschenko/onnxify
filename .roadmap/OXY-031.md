## Summary

Add compiler-owned mappings for the audited shape-manipulation operators and tensor factories needed by existing compiler use cases.

## Depends On

- [OXY-024](OXY-024.md).
- [OXY-034](OXY-034.md).

## Goals

- Enumerate the complete supported shape/factory set and its static, symbolic, and dtype constraints from upstream tests.
- Implement reusable bidirectional mappings in `Onnxify.Compiler`.
- Preserve explicit diagnostics for dynamic or unsupported argument forms.

## Implemented Scope

- ONNX `Flatten` with any valid static axis maps bidirectionally to TorchSharp `torch.flatten(input, start_dim: axis)` and `input.flatten(axis)`. Dynamic axes and `end_dim` values other than `-1` are diagnosed; axes are checked against known input rank.
- ONNX `Transpose` with an explicit valid permutation maps bidirectionally to `Tensor.permute(new long[] { ... })`. Default/null permutations and malformed permutations are diagnosed because the current compiler printer does not resolve rank-dependent default axes.
- The current runtime parity fixture covers `float32`; other tensor element types are preserved by the shape operation but have not yet been added to the compiler runtime matrix.

## Upstream Test Provenance

- ONNXScript: `third_party/onnxscript/tests/function_libs/torch_lib/ops_test_data.py`, `TorchLibOpInfo("flatten", core_ops.aten_flatten)`.
- ONNX Runtime: `third_party/onnxruntime/onnxruntime/test/providers/cpu/nn/flatten_op_test.cc`, `FlattenOpTest.Flatten_default_axis` and `FlattenOpTest.Flatten_invalid_axis`.

## Tests

- Pair tests in both directions for each declared operator and supported shape/dtype case.
- Assert graph/source structure, ONNX Runtime session creation where executable, and deterministic runtime parity.
- Include exact ONNXScript and ONNX Runtime source provenance.
- `Onnxify.Compiler.Tests/ShapeCompilerTests.cs` verifies typed Flatten import/export, generated TorchSharp execution, ONNX Runtime parity, and diagnostics for an unsupported axis and dynamic `start_dim`.

## Acceptance Criteria

- Every declared case has paired verification or an explicitly tested one-way classification and documented limitation.
