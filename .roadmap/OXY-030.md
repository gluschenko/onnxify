## Summary

Add compiler-owned bidirectional mappings for ONNX `MatMul` and `Gemm`, including the TorchSharp `matmul`, `mm`, `bmm`, `addmm`, and `torch.nn.functional.linear` call forms.

## Depends On

- [OXY-024](OXY-024.md).
- [OXY-034](OXY-034.md).

## Implemented Scope

- `MatMul` handles vector-vector, vector-matrix, matrix-vector, matrix-matrix, and batched inputs, including compatible batch broadcasting.
- `Gemm` handles rank-2 A/B, `transA`, `transB`, `alpha`, `beta`, and an optional broadcastable C input. `linear` maps weights through `transB=1`; `addmm` maps C/A/B and scalar alpha/beta to the ONNX input and attributes.
- The runtime-verified dtype intersection is `float32`, `float64`, `int32`, and `int64` for MatMul, and `float32` and `float64` for Gemm imported from ONNX. TorchSharp-source imports use the compiler's current `float32` input metadata and therefore export Gemm as `float32`; source-side dtype inference is not represented by this frontend.
- Diagnostics cover incompatible known MatMul inner/batch dimensions, unsupported matrix dtypes, Gemm rank, transpose flags, incompatible bias broadcasting, and incompatible bias element types.
- Convolution, pooling, `addbmm`, and shape-changing operators remain out of scope.

## Upstream Test Provenance

- ONNXScript: `third_party/onnxscript/tests/function_libs/torch_lib/ops_test_data.py`, cases `aten_matmul`, `aten_mm`, `aten_bmm`, and `aten_addmm`.
- ONNX Runtime: `third_party/onnxruntime/onnxruntime/test/providers/cpu/math/matmul_test.cc` (`MatMulFloatType`, `MatMulDoubleType`, `MatMulInt32Type`, `MatMulInt64Type`) and `third_party/onnxruntime/onnxruntime/test/providers/cpu/math/gemm_test.cc` (`GemmOpTypedTests.TestGemmAlphaBeta`, which runs for float and double, plus transpose, alpha, and beta cases).

## Tests

- `Onnxify.Compiler.Tests/MatrixMultiplicationCompilerTests.cs` checks both mapping directions, identity/capability, generated source/graph, runtime execution and numerical parity for vectors, matrices, batched MatMul and batch broadcasting; Gemm transpose, bias, alpha/beta; and `linear` with and without bias (including import of the bias-free Gemm back into generated TorchSharp).
- Tested diagnostics cover incompatible inner and batch dimensions, unsupported dtype, invalid Gemm transpose flags, invalid Gemm rank, and a non-broadcastable bias.
- Gemm `float64` is exercised from a typed ONNX graph through generated TorchSharp execution and ONNX Runtime parity. The TorchSharp source frontend records tensor inputs as `float32`, so source-originated `float64` Gemm is not claimed.
- Full compiler test runs on 2026-10-07: `dotnet test src/Onnxify.Compiler.Tests/Onnxify.Compiler.Tests.csproj -f net8.0 --no-restore -v:minimal` (144 passed) and the same command with `net10.0` (144 passed).
