- Document compiler ownership, dependency direction, API examples, migration rules, and mandatory two-way operator verification.
- Refresh relevant package docs/release notes and generated references when public behavior or operator coverage changes.
- Remove dead duplicate paths or mark them as compatibility-only with an explicit retirement condition.
