## Summary

Add shared compiler mappings for the audited basic arithmetic operator family and its supported TorchSharp spellings, including ONNX/TorchSharp broadcasting behavior.

## Depends On

- [OXY-024](OXY-024.md).

## Goals

- Select the complete supported arithmetic set from ONNXScript and ONNX Runtime source tests before implementation.
- Implement mappings only in `Onnxify.Compiler` and preserve explicit constraints for supported overloads and broadcasting.
- Keep unsupported signatures diagnostic and generic unknown ONNX operators preservable.

## Tests

- Add paired ONNX-to-TorchSharp and TorchSharp-to-ONNX tests for each declared operator and supported broadcast case.
- Assert mapping identity/capability, graph or generated source structure, ONNX Runtime session creation, and deterministic numerical parity.
- Link each test to exact ONNXScript and ONNX Runtime source cases.

## Acceptance Criteria

- Every operator in the declared family has paired directional coverage or an explicitly tested one-way capability.
- Broadcast/type limitations and unsupported overload diagnostics are recorded alongside the tests.
