## Summary

Add shared compiler mappings for audited reductions and selection operators that change shape or select values across dimensions. Pointwise selection, comparisons, logical operators, and casts belong to OXY-029.

## Depends On

- [OXY-024](OXY-024.md).

## Goals

- Identify complete supported operators and semantic variants from ONNXScript and ONNX Runtime source tests.
- Implement mappings in `Onnxify.Compiler` with normalized attributes and deliberate handling of optional inputs.
- Provide explicit diagnostics for unsupported overloads and lossy cases.
- Exclude operations whose output is elementwise with respect to broadcasted inputs; those are owned by OXY-029.

## Tests

- Add paired ONNX-to-TorchSharp and TorchSharp-to-ONNX tests for each declared operator and semantic variant.
- Verify graph/source structure, runtime session creation where executable, and deterministic parity.
- Record exact upstream sources and reasons for skipped cases.

## Acceptance Criteria

- Every declared case has paired verification or an explicitly tested one-way classification with documented constraints.
